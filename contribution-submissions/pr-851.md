# feat(csv): add opt-in spreadsheet text escaping

## Summary
Refs #851 (feature proposal; retain the issue for exhaustive emitter-level acceptance).

Add --format csv-safe, format=csv-safe on entries export, and csv_safe=true for negotiated REST CSV. One serializer escapes dangerous leading characters in every serialized cell, including headers and signed numbers. Raw csv remains the default and its existing serialization path is unchanged.
