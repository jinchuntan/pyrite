# fix(links): warn consistently on undeclared relations

## Summary
Fixes #1274.

A shared vocabulary helper reports undeclared relations without rejecting or changing the requested link. Single and bulk link writes, CLI link/create, MCP and QA expose the warning. Declared relations and aliases remain quiet; backlinks retain their documented inverse behavior.

## Plan / claim
This PR is the claim: warn using the global core/plugin vocabulary, propagate warnings across the enumerated link writers, and report hand-written unknown relations through QA.
